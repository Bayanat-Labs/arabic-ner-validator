# مدقّق مواضع الكيانات المسمّاة العربية

من **بيانات لابز**. الإصدار 0.1.0.

> The Arabic text has not yet been reviewed by a native Arabic writer; the English governs.

يفحص `arabic-ner-validator` وسوم الكيانات المسمّاة العربية قبل استعمالها في التدريب: مواضع محسوبة بوحدة خاطئة (نقاط الترميز أو وحدات UTF-16 أو بايتات UTF-8 أو العناقيد الكتابية)، ونصًّا تغيّر بعد الوسم (NFC وNFKC وحذف التطويل أو التشكيل وفواصل الأسطر CRLF وLF وعلامة ترتيب البايتات)، وحدود امتدادات تفصل الحرف عن حركته أو السابقة عن كلمتها، ومحارف التحكم الاتجاهية وصفرية العرض عند الحدود، والتداخل والتعشيش، وأخطاء وسوم BIO وBIOES وBILUO. ويقرأ 6 صيغ.

تُكتب الإصلاحات فرقًا للمراجعة في المواضع فقط، ولا تُطبَّق إلا بطلب صريح، ولا تُغيَّر الوسوم ولا النص أبدًا. ولا تُخمَّن وحدة المواضع أبدًا؛ وإذا غابت أو كانت خاطئة ذكر التقرير الوحدة المطابقة.

- التطبيق في المتصفح (لا يُرفع شيء): https://huggingface.co/spaces/Bayanat-Labs/arabic-ner-offset-validator
- حالات الاختبار مجموعةَ بيانات: https://huggingface.co/datasets/Bayanat-Labs/arabic-ner-offset-fixtures

## التثبيت

```bash
pip install "git+https://github.com/Bayanat-Labs/arabic-ner-validator@v0.1.0"
```
